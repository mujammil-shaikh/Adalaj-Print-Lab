# Adalaj Print Lab

Universal mark & code print management platform for multi-pack packaging, real-time batch allocation, 1-bit BMP generation, and direct hardware communication.

- **Production App:** [https://adalaj-print-lab.vercel.app](https://adalaj-print-lab.vercel.app)
- **GitHub Repository:** [https://github.com/mujammil-shaikh/Adalaj-Print-Lab](https://github.com/mujammil-shaikh/Adalaj-Print-Lab)

## Run Locally

**Prerequisites:** Node.js, pnpm

1. Install dependencies:
   `pnpm install`
2. Run development server:
   `pnpm run dev`
3. Run test suite:
   `pnpm test`
4. Build production bundle:
   `pnpm run build`
